# kubebottle/artwork

Brand and mascot artwork for the kubebottle organization. All images in this repository are licensed under [CC BY 4.0](LICENSE), unless noted otherwise.

## `kubebottle/` — organization brand

| File | Description |
| --- | --- |
| `avatar-v1-vector.png` | Current organization avatar (adopted 2026-11-15): refined vector version of the original — blue bottle, white 7-spoke Kubernetes helm wheel, bubbles, thin highlight. |
| `avatar-v2-handdrawn.png` | Alternate: the same bottle redrawn in the crema mascot's hand-drawn pen-and-watercolor style, non-anthropomorphic, cork top. |
| `avatar-v3-minimal-badge.png` | Alternate: minimal blue-bottle × cloud-native badge, made to stay legible at 32×32. Draft note: the helm wheel was rendered with 8 spokes instead of the intended 7 — not adopted. |

## Style

Hand-drawn pen line + marker / watercolor, in the spirit of Renée French's Go Gopher: slightly asymmetric, paper texture, no text. The mascot is an original character inspired by that style, not the Go Gopher itself.
